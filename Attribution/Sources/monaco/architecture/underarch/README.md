# Larvotto lower woodland

The old foliage routine excluded the full bridge plan in two dimensions. This removed planting from real lower woodland beneath the arch. The replacement runs after terrain and architecture, reads the actual lower ground and actual concrete soffit triangles, and checks complete emitted crowns against the bridge.

Only lower Runoff within the literal mixed-forest and bridge overlap is reclassified. Race pavement, barrier skins, property bodies, pedestrian paths, existing rock and ivy, and the overhead bridge remain protected. Positions and species are estimates. The bounded source and camera review permits a cooked trial; it does not grant native visual acceptance.
