# Mixed natural cliff cover

The lower ravine contains old Grass faces that look like a manicured lawn, while the primary photographs show a mixture of exposed rock and vegetation. This final scenery pass changes only those whole faces to the existing MonacoNaturalGround material.

The finite mask joins the original ravine to literal natural-wood way 967508764. The old x=-12 m limit came from a terrain-form experiment, so it is not kept as an artificial land-cover seam. Buildings, formal gardens, paths, belvedere, racing pavement and protection retain their exclusions. Existing rock and ivy stay distinct.

Run after all current ground and foundation producers. Every position, normal, UV, row order, existing plant and driving-data byte stays unchanged. The material has a source-qualified general role; cooked appearance remains subject to review.
