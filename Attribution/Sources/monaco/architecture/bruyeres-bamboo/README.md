# Les Bruyères narrow-leaf garden

The dated 28 September 2025 original and CCA's completed-project photograph show
an overlapping mass of narrow arching leaves below the rounded balconies. The
previous sparse, tiered cane recipe resembled a nursery in the driving view.

The replacement retains all 220 original estimated root positions, the sloping
bed, retaining walls, two palms, six lower understory clumps and the protected
open portal. Its closed leaves are original geometry; no photograph is used as
a texture. The existing random draws remain in the root recipe so later root
positions cannot drift.

`source-qualification.json` records the dated photo controls, metric uncertainty,
actual root levels and material estimates. The 14.7–16.4 m absolute canopy is a
photo-based reconstruction with ±2 m uncertainty. Stem heights follow each old
root, rather than adding the same height to the rising rear bed. Species and
individual planting positions are unmeasured.

The frozen private source/camera review permits a cooked trial. It does not
approve native shading, foliage aliasing, performance or the whole Monaco scene.
Production uses the typed recipe in `foreground-properties.json`; ignored proof
buffers and photographs are not runtime or generation dependencies.
