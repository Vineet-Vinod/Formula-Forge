# Heydar Aliyev Foundation frontage

This is a source-qualified working model, awaiting packaged visual review.
The literal mapped owner is OSM way 133160748 at Niyazi Street 3. The baseline
19,930 generic rows are bound exactly to the saved city meshes. At station 3900 m,
the near right-hand facade is this owner; the larger grid block farther ahead is
separate SOCAR way 133160749. Do not transfer this building's identity to it.

The retained views support six principal facade bands, one tall patterned entry
panel, a rounded corner, heavy cornice and blue cupola. The 8-level OSM tag is
not an eight-row facade survey. Body height 27.2 m preserves the old tag-derived
envelope with ±4 m uncertainty. Corner, roof, panel placement and unobserved rear
openings remain architectural estimates. The rounded corner stays inside the
mapped owner; its removed corner area is about 2.8 m². The existing floor datum,
surrounding ground and native physical data are preserved.

The model uses original geometry and relief, not photographic textures. The two
review image URLs and hashes are in `source-registration.json`; their licences
are not assumed to permit image redistribution. A visually similar contractor
image was rejected because it depicts a different four-storey building.
