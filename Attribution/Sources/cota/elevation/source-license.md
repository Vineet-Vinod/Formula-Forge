U.S. Geological Survey,3D Elevation Program,TX Central B1 2017 one-metre bare-earth DEM. USGS data are public domain unless otherwise indicated. Original service/catalog metadata, bounded F32 exports and exact request URLs are retained.

The reconstruction modifies numeric heights by CRS transformation, bilinear resampling, a2m road-noise filter and a shared relative datum subtraction. No height rescale or canopy/roof DSM is used. Historical officialF1chart digits remain retained for comparison; no reference video or chart pixels ship.
