# PMSP GeoSampa lidar attribution

Prefeitura Municipal de São Paulo (PMSP), GeoSampa M3DC, 2017 survey.

The data owner's [GeoSampa licence notice](https://prefeitura.sp.gov.br/web/licenciamento/w/licen%C3%A7a-para-uso-de-dados-do-geosampa), published 3 April 2025 and reviewed 7 September 2026, specifies Creative Commons Attribution Share-Alike 4.0 for GeoSampa data, under administrative proceeding SEI 6066.2020/0003044-4. Retain source attribution and the same licence for derived data.

The older AWS registry identifies GPLv3. This reconstruction relies on the owner's later, explicit GeoSampa CC BY-SA 4.0 licence; the AWS bucket is the delivery mirror for the same PMSP source. Cropping, class-2 ground selection, local plane sampling and profile filtering are modifications by Formula Forge contributors.
