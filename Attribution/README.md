# Asset attribution

These notices and manifests accompany the accepted Silverstone, Monza, Interlagos
and shared scenery assets copied into `Content/Generated`. They retain source
URLs, licences and original authoring provenance. Historical paths inside these
records describe the original authoring project, not build dependencies here.

The native Unreal assets are the editable source assets for this project.
The vehicle simulation and game code retain the original MIT licence at the root.
Unreal Engine is installed separately under its own licence.

[Retained asset source notices](ASSET_LICENSES.md) include the original geometry,
texture, vegetation and event-artwork credits and licence statements.
